# Case Lab

Бесплатный симулятор открытия CS2-кейсов для Telegram Mini App. Сейчас доступен **Kilowatt Case**: 17 обычных предметов и 13 вариантов редкого ножа с названиями и изображениями из каталога игры. Результат выбирается сервером; лента лишь показывает его. Платежей, ставок, выдачи предметов и реальных призов нет. Проект не связан с Valve.

## Локальный запуск

Нужны Node.js 20.9+, Bun 1.3+, PostgreSQL и Telegram-бот с настроенным Main Mini App.

```bash
bun install
cp example.env .env.local
# Заполни DATABASE_URL и TELEGRAM_BOT_TOKEN в .env.local
bun run db:migrate
bun run dev
```

Токен бота не присылай в чат и не коммить `.env.local`. Для открытия из Telegram URL приложения должен быть доступен клиенту Telegram по HTTPS; обычный `localhost:3000` в Safari позволяет проверить интерфейс и звук, но без действующей Telegram-сессии открыть кейс нельзя. Используй Main Mini App или menu button: некоторые способы запуска Telegram не передают пользователя в `initData`.

Проверки: `bun run test`, `bun run typecheck`, `bun run lint`, `bun run format:check`, `bun run build`. PostgreSQL-интеграционные тесты включаются только с `TEST_PG_SOCKET` — путём к Unix-сокету отдельной тестовой базы `cases_test`; обычный прогон их пропускает.

## Как устроено открытие

- Telegram передаёт исходную `initData`; сервер проверяет HMAC и возраст данных, затем создаёт собственную HttpOnly-сессию. `initDataUnsafe` и переданный браузером ID не используются как подтверждение личности. [Подробности и источники](docs/telegram-initdata.md).
- Server Action принимает только ID кейса и UUID запроса. В PostgreSQL под блокировкой строки пользователя проверяется лимит **5 открытий за календарный день UTC**, выбирается предмет и одной транзакцией записываются открытие и экземпляр предмета. Повтор запроса с тем же UUID не выдаёт второй предмет.
- Коллекция и история читаются из PostgreSQL. Из браузерного `localStorage` выигрыши не импортируются. Если страница закрылась во время анимации, серверное открытие уже сохранено.
- Шансы **симулятора**, не официальные шансы Valve: Mil-Spec 79,92%, Restricted 15,98%, Classified 3,20%, Covert 0,64%, редкий особый предмет 0,26%. Внутри группы предметы выбираются равновероятно.
- Звук синтезируется через Web Audio, файлов Valve нет. «Проверить звук» запускает сигнал прямо по нажатию — удобно для диагностики Safari. Ошибка звука не отменяет открытие.
