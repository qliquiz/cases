# Case Lab

Бесплатный прототип симулятора открытий: один вымышленный кейс, прозрачные шансы и серверный выбор результата. Нет денег, вывода предметов, ставок и реальных призов. Проект не связан с Valve или Counter-Strike.

## Запуск

Требуются Node.js 20.9+ и Bun 1.3+. Bun устанавливает зависимости и запускает команды проекта; Next.js работает на Node.js.

```bash
bun install
bun run dev
```

Откройте http://localhost:3000.

Проверки: `bun run test`, `bun run typecheck`, `bun run lint`, `bun run format:check`, `bun run build`. Для CI используйте `bun install --frozen-lockfile`.

## Что реализовано

- Next.js App Router, TypeScript, Tailwind CSS.
- Один демо-кейс и список вымышленных предметов с шансами.
- Открытие через Server Action. Таблица выпадения и генератор случайных чисел находятся на сервере.
- Проверки всех границ диапазонов выпадения.

Результаты сейчас не сохраняются. Авторизации, Telegram, базы данных и рекламы пока нет. Подробный следующий этап — [docs/mvp.md](docs/mvp.md).
