# CaseGo

Светлая и тёмная темы: по умолчанию тема устройства или Telegram; ручной выбор — в шапке сайта.
[Поведение и проверка тем](docs/themes.md).

[Тестовый рейтинг игроков](docs/leaderboard.md) — отдельная страница `/leaderboard`: топ-50 по уникальным предметам,
собственное место и публичный ник по желанию. Для этой версии нужна миграция `006-leaderboard`.

Бесплатный симулятор открытия CS2-кейсов для обычного веба и Telegram Mini App. Доступны **Kilowatt, Chroma, Chroma 2,
Spectrum и Spectrum 2** с названиями и изображениями из каталога игры. [Составы и источники](docs/case-catalog.md).
Лимит в десять открытий общий для всех кейсов; в тестовом режиме его можно бесплатно сбрасывать без ограничений.
Альбом показывает прогресс выбранного кейса. Результат выбирается
сервером; лента лишь показывает его. Платежей, ставок, выдачи предметов и реальных призов нет. Проект не связан с Valve.

## Локальный запуск

Нужны Node.js 20.9+, Bun 1.3+ и PostgreSQL. Для email-входа нужен SMTP; для Telegram — бот с Main Mini App и/или
настройками Login в BotFather.

```bash
bun install
cp example.env .env.local
# Заполни DATABASE_URL, AUTH_SECRET и настройки способов входа
bun run db:migrate
bun run dev
```

Секреты не присылай в чат и не коммить `.env.local`. Сгенерируй `AUTH_SECRET`, например командой
`openssl rand -base64 32`. Настройка всех переменных, Telegram redirect URL и SMTP описана
в [веб-авторизации](docs/web-auth.md).

Для ответа бота на `/start` и кнопки запуска Mini App подключите [Telegram webhook и меню](docs/telegram-bot.md).
Это часть того же приложения; одного `TELEGRAM_BOT_TOKEN` недостаточно. Регистрация выполняется отдельно после деплоя,
не во время сборки.

Обычный сайт поддерживает вход по email-коду и через Telegram. Telegram SDK загружается только при запуске Mini App;
веб-вход по email от него не зависит. Аккаунт создаётся при первом подтверждённом входе. Чтобы сохранить одну коллекцию,
второй способ входа нужно **привязать из уже открытого аккаунта**.

`bun run db:migrate` применяет версионированные миграции в транзакции. Старая Telegram-схема переводится на внутренние
UUID с сохранением сессий, истории и лимита; повторный запуск безопасен. Перед миграцией рабочей БД сделай резервную
копию. Сам файл `db/schema.sql` — историческая первая миграция, не актуальная схема для ручного запуска.

Проверки: `bun run test`, `bun run typecheck`, `bun run lint`, `bun run format:check`, `bun run build`.
PostgreSQL-интеграционные тесты включаются только с `TEST_PG_SOCKET` — путём к Unix-сокету отдельной тестовой базы
`cases_test`; обычный прогон их пропускает.

## Как устроено открытие

- В Mini App Telegram передаёт исходную `initData`; сервер проверяет HMAC и возраст данных, затем создаёт собственную
  HttpOnly-сессию. `initDataUnsafe` и переданный браузером ID не используются как подтверждение
  личности. [Подробности и источники](docs/telegram-initdata.md).
- Server Action принимает только ID кейса и UUID запроса. В PostgreSQL под блокировкой строки внутреннего аккаунта
  проверяется лимит **10 открытий**, выбирается предмет и одной транзакцией записываются открытие
  и экземпляр предмета. Повтор запроса с тем же UUID не выдаёт второй предмет.
- «Сбросить лимит» возвращает 10 попыток на сервере, не удаляя историю/предметы. Доступно любому вошедшему пользователю
  сколько угодно раз, включая production: это временный тестовый режим, не защита от массовых открытий.
  Лимит также автоматически обновляется в 00:00 UTC. Перед публикацией этого изменения нужна миграция `005-opening-limit-reset` (`bun run db:migrate`).
- Коллекция, история и лимит общие для привязанных способов входа и читаются из PostgreSQL. Из браузерного
  `localStorage` выигрыши не импортируются. Если страница закрылась во время анимации, серверное открытие уже сохранено.
- Шансы **симулятора**, не официальные шансы Valve: Mil-Spec 79,92%, Restricted 15,98%, Classified 3,20%, Covert 0,64%,
  редкий особый предмет 0,26%. Внутри группы предметы выбираются равновероятно.
- Звуки открытия синтезируются через Web Audio, файлов Valve нет. Отдельных кнопок управления звуком нет.
  Аудио активируется по нажатию для совместимости с Safari. Ошибка звука не отменяет открытие.
