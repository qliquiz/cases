# Case Lab

Бесплатный прототип симулятора открытий CS2. Сейчас доступен настоящий **Kilowatt Case**: 17 обычных предметов и 13 вариантов редкого ножа, с названиями и изображениями из каталога игры. Результат выбирается на сервере, после чего клиентская лента прокручивается до него. Платежей, выдачи предметов, ставок и реальных призов нет. Проект не связан с Valve.

## Запуск

Требуются Node.js 20.9+ и Bun 1.3+. Bun устанавливает зависимости и запускает команды проекта; Next.js работает на Node.js.

```bash
bun install
bun run dev
```

Откройте http://localhost:3000.

Проверки: `bun run test`, `bun run typecheck`, `bun run lint`, `bun run format:check`, `bun run build`. Для CI используйте `bun install --frozen-lockfile`.

## Каталог и симуляция

- Снимок данных Kilowatt Case получен 25 сентября 2026 года из [неофициального CSGO-API](https://github.com/ByMykel/CSGO-API). Исходная запись включает `contains` и `contains_rare`; в проект сохранены только ID, названия, редкость и URL изображений. Изображения загружаются браузером с CDN Steam и не копируются в репозиторий.
- Веса **симулятора**, не официальные шансы Valve: Mil-Spec 79,92%, Restricted 15,98%, Classified 3,20%, Covert 0,64%, редкий особый предмет 0,26%. Внутри выбранной группы предметы выбираются равновероятно.
- Server Action принимает только ID кейса. Сервер выбирает предмет; браузер строит декоративную ленту и останавливает её на полученном результате. При `prefers-reduced-motion` анимация пропускается.
- Звук синтезируется в браузере через Web Audio: щелчок при прохождении карточки через метку и сигнал результата. Звуковых файлов Valve нет. Кнопка «Звук» позволяет отключить воспроизведение; если браузер не поддерживает Web Audio, открытие продолжает работать без звука.
- Автоматические тесты проверяют состав кейса, границы групп выпадения, отклонение неверного ID, остановку ленты на серверном результате и наличие управления звуком.

Доступность изображений по URL и MIT-лицензия каталога **не дают разрешения** на коммерческое использование контента CS2. До публичного запуска с рекламой нужно отдельно решить вопрос прав на изображения. Результаты сейчас не сохраняются. Авторизации, Telegram, базы данных и рекламы пока нет. Подробный следующий этап — [docs/mvp.md](docs/mvp.md).
