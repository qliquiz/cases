## Источники и границы достоверности

Новые составы, исходные английские названия, ID, изображения Steam CDN и фазы взяты из закреплённого снимка
[CSGO-API crates.json, commit 4734df478335bb09bba52cfca9d4023167394e0c](https://github.com/ByMykel/CSGO-API/blob/4734df478335bb09bba52cfca9d4023167394e0c/public/api/en/crates.json).
Нужные поля сохранены в `src/game/additional-cases.json`; импорт не зависит от доступности API при запуске.
Списки ножей в этом неофициальном каталоге поддерживаются вручную, поэтому закрепление версии даёт воспроизводимость,
но не означает официальную верификацию Valve. Перед обновлениями требуется повторная сверка.

Общие составы и поколения ножей сверены с первичными объявлениями Valve:

- [Chroma, 8 января 2015](https://blog.counter-strike.net/2015/01/11109/) — название публикации Full Spectrum не означает Spectrum Case.
- [Chroma 2, 15 апреля 2015](https://blog.counter-strike.net/2015/04/11845/) — шесть покрытий ножей Chroma.
- [Spectrum, 15 марта 2017](https://blog.counter-strike.net/2017/03/18198/) — 17 предметов и второе поколение ножей с покрытиями Chroma.
- [Spectrum 2, 14 сентября 2017](https://blog.counter-strike.net/2017/09/19289/) — 17 предметов и тот же класс редких ножей.

Chroma и Chroma 2 делят один редкий пул: Bayonet, Flip Knife, Gut Knife, Karambit, M9 Bayonet.
Spectrum и Spectrum 2 делят другой: Bowie Knife, Butterfly Knife, Falchion Knife, Huntsman Knife, Shadow Daggers.
У каждого пула покрытия Marble Fade, Tiger Tooth, Doppler, Damascus Steel, Ultraviolet, Rust Coat.
Doppler представлен семью фазами: Ruby, Sapphire, Black Pearl и Phase 1–4. Получается 5 моделей × (5 покрытий + 7 фаз Doppler) = 60 вариантов.
Фаза отображается отдельно от исходного названия. Wear, float, pattern и StatTrak не моделируются.

Шансы остаются моделью симулятора: те же пять весов редкости, равновероятный выбор внутри группы.
Это относится и к фазам Doppler, а не воспроизводит их реальную редкость. Нельзя называть эти проценты шансами Valve.
Изображения не копируются в репозиторий; права на контент не следуют из доступности CDN или лицензии кода каталога.

## Поведение

- Переключатель меняет кейс открытия, состав, шансы отдельных предметов и альбом. При перезагрузке выбран Kilowatt.
- Во время запроса/прокрутки выбор заблокирован; при переключении прошлый результат убирается.
- Сервер принимает только известные ID кейсов и выбирает предмет из соответствующего пула.
- Общий лимит — пять открытий за день UTC на аккаунт, не на кейс. Повтор UUID с другим кейсом отклоняется.
- Коллекция и история общие, история показывает кейс происхождения. Общие ножи засчитываются в обоих подходящих альбомах без создания дополнительных экземпляров.
- Сохранённые открытия Kilowatt и их версия `kilowatt-sim-v1` не изменяются. Новые кейсы имеют версии `<case-id>-sim-v1`.
- Новых миграций нет: `case_id`, снимок предмета и версия распределения уже хранятся в БД.

## Проверки

`bun run test` проверяет названия, группы редкости, уникальность ID, ножевые модели/фазы, суммы вероятностей,
открытие каждого кейса и альбомы. С `TEST_PG_SOCKET` также проверяются параллельные открытия разных кейсов,
общий лимит, происхождение предметов и повтор UUID.

На отдельном локальном сервере, подключённом к `cases_test`:

```sh
CASE_TEST_BASE_URL=http://127.0.0.1:3098 TEST_PG_SOCKET=/path/to/.s.PGSQL.55439 node --import tsx scripts/cases-smoke.mts
CASE_TEST_BASE_URL=http://127.0.0.1:3098 TEST_PG_SOCKET=/path/to/.s.PGSQL.55439 CASE_TEST_BROWSER=webkit node --import tsx scripts/cases-smoke.mts
```

Браузерная проверка использует локальную тестовую сессию, а не настоящий Telegram/email-вход. Проверяет выбор,
содержимое, два сохранённых открытия, блокировку переключения во время анимации, общий лимит, историю,
перезагрузку и мобильную ширину. Тестовый аккаунт удаляется после проверки.
