# Коллекция-альбом

## Правила

- Альбом Kilowatt Case содержит 30 уникальных позиций текущего каталога: 17 обычных и 13 редких вариантов.
- Уникальность определяется `itemId`, не названием. Прогресс — количество собранных позиций из 30; процент округляется вниз.
- Каждая копия после первой — дубликат: три одинаковых предмета дают одну позицию прогресса и два дубликата.
- «Всего» — все экземпляры в аккаунте; «Не хватает» — отсутствующие позиции текущего альбома.
- Собранные предметы показывают сохранённый снимок, недостающие — изображение и название из каталога с подписью «Ещё не выпал».
- Фильтры «Все / Собрано / Не хватает» относятся только к текущему альбому. Обычные и редкие предметы имеют отдельные счётчики.
- Предметы вне актуального каталога остаются в раскрываемом разделе и истории; они входят в общее количество и дубликаты, но не увеличивают прогресс альбома.
- История открытий и обновление суточного лимита сохраняются.

## Данные и границы

Компонент получает существующую серверную коллекцию. После открытия или смены аккаунта пересчитывается из новых props;
отдельной копии коллекции в браузерном хранилище нет. Только выбранный фильтр живёт в состоянии компонента.
Миграции, изменения Server Actions, вероятностей, авторизации и лимита не нужны.
Наград за завершение, обмена дубликатов, торговли и новых кейсов в этом срезе нет.

## Проверки

`bun run test` проверяет пустой, частичный и полный альбом, повторы, редкие варианты и предметы вне каталога.

Для браузерной проверки запустить локальный Next.js сервер, затем:

```sh
CASE_TEST_BASE_URL=http://127.0.0.1:3098 bun run test:collection
CASE_TEST_BASE_URL=http://127.0.0.1:3098 COLLECTION_TEST_BROWSER=webkit bun run test:collection
```

Скрипт собирает отдельный React-стенд во временную директорию и использует реальный CSS приложения. Стенд не является
маршрутом приложения, не обращается к БД и не открывает кейсы. Проверяет фильтры, новое выпадение через обновление props,
сброс данных аккаунта, пустые состояния, историю, обновление лимита, клавиатуру и ширины 320/390/1024 в обеих темах.
Это компонентная браузерная проверка, не end-to-end проверка настоящего Telegram или PostgreSQL.
