# Тема оформления

## Поведение

- По умолчанию выбран режим «Авто»: тема Telegram в Mini App, тема устройства в обычном вебе.
- При загрузке Mini App до готовности SDK используется тема устройства; после готовности — `WebApp.colorScheme`.
- «Светлая» и «Тёмная» имеют приоритет над Telegram и устройством. «Авто» возвращает следование внешней теме.
- Смена темы устройства или Telegram применяется без перезагрузки.
- Только настройка оформления сохраняется в `localStorage` (`casego-theme`) и синхронизируется между вкладками.
  Аккаунты, коллекция и лимиты по-прежнему хранятся на сервере. Выбор не переносится между устройствами.
- При недоступном хранилище ручной выбор работает до закрытия страницы. Невалидные значения означают «Авто».
- Начальная тема устанавливается inline-скриптом в `head` до гидратации React; CSS поддерживает системную тему и без JS.
  `applyTheme` самодостаточна: её сериализованная копия не должна зависеть от переменных модуля.
- Цветовые переменные в `globals.css` описывают обе палитры. Лента и подложки изображений остаются тёмными;
  цвета редкости CS2 не меняются.

## Проверенные API и решение

Проверено 26 сентября 2026 года. Telegram предоставляет `WebApp.colorScheme` (`light` или `dark`),
`onEvent`/`offEvent` и событие `themeChanged`; обработчик не получает параметров, актуальная схема читается из WebApp.
Источник: [официальная документация Telegram Mini Apps](https://core.telegram.org/bots/webapps#events-available-for-mini-apps).

Приложение подписывается на событие после готовности уже используемого Telegram SDK. Для темы отдельная загрузка SDK
в обычном вебе не нужна. Цветовая схема Telegram влияет только на оформление, не подтверждает личность пользователя.

Решение для Next.js: интерактивный `ThemePicker` — клиентский компонент; страница и layout остаются серверными.
Источник: локальная документация установленного Next.js
`node_modules/next/dist/docs/01-app/01-getting-started/05-server-and-client-components.md`.

## Проверка

`bun run test`, `bun run typecheck`, `bun run lint`.

На отдельном локальном сервере (без production БД):

```bash
DATABASE_URL='' bun run dev --hostname 127.0.0.1 --port 3098
CASE_TEST_BASE_URL=http://127.0.0.1:3098 bun run test:theme
THEME_TEST_BROWSER=webkit CASE_TEST_BASE_URL=http://127.0.0.1:3098 bun run test:theme
```

Браузерный тест проверяет системную тему, ручной приоритет, перезагрузку, вкладки, события Telegram через mock SDK,
запрет хранилища, тему до запуска React и мобильную ширину. Настоящий Telegram-клиент проверяется отдельно вручную.
